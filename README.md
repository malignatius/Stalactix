# Stalactix

A two-player, split-screen cave shooter that runs in the browser — one self-contained HTML file, no install.

**Play:** open `index.html` in a desktop browser (or the GitHub Pages link, once enabled).

Two pilots, one cave — play a friend on the same keyboard, or pick **vs CPU** on the title screen (Easy / Normal / Hard). Shoot each other down: every wreck scores a point for the other side. No brakes, walls bite, and backing onto your own pad docks you for repairs. First to 5 wins, then a new cave is generated.

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Rotate | A / D | ← / → |
| Thrust | W | ↑ |
| Fire | Space | Enter, `,` or Right Shift |
| Mine / missile / shield | S | ↓ |

| Key | |
|---|---|
| P | Pause |
| Esc | Back to title |
| M | Music on/off |
| N | Mute all sound |
| R | New cave |
| T / Y / L | Tuning, graphics and sound panels |
| 1–7 / Shift+1–7 | Test power-ups for P1 / P2 |

## Power-ups

Triple shot, laser, homing missiles, mines, shield, flamethrower and repair, dropped in mystery crates. Watch out for the black holes that open in pairs — they pull you in and throw you out the other side.

## Files
